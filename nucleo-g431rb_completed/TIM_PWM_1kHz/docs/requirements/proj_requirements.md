# 项目任务需求文件

## 1. 项目信息

- 项目名称：TIM_PWM_1kHz
- 项目类型：STM32 基础实验（定时器 PWM 输出）
- 项目目标：使用通用定时器 TIM2 通道 1（Channel 1）输出 PWM 信号驱动板载 LD2 LED，PWM 频率约为 1 kHz，占空比在 10%~90% 之间周期性往复变化，实现呼吸灯效果。
- 开发板型号：nucleo-g431rb
- MCU型号：STM32G431RBT6
- 文件状态：已确认

## 2. 项目功能要求

### PR-001 定时器 PWM 信号生成

- 功能要求：
  使用 TIM2 的 PWM 输出通道（Channel 1），配置为 1 kHz 的 PWM 信号。PWM 频率由定时器时钟、预分频器和自动重载值共同决定，输出引脚为 PA5。
  TIM2 时钟频率为 160 MHz，配置预分频器 Prescaler=159 时（分频 1/160），自动重载值 Period=999 时可得 PWM 频率约 1 kHz。

- 条件与边界：
  PWM 频率固定为约 1 kHz（Period=999）。占空比通过比较值 Pulse 在 10%~90% 之间周期性往复变化，实现呼吸灯效果，变化过程平滑无跳变。PA5 同时连接板载 LD2 LED，PWM 输出的亮度变化可直观反映占空比变化。

### PR-002 呼吸灯效果

- 功能要求：
  以固定起始占空比 10% 开始，占空比逐步增大至 90%，再逐步减小回 10%，如此循环往复，驱动 LD2 呈现呼吸灯效果（由暗到亮、由亮到暗的周期变化）。占空比变化速率应保证视觉效果平滑、无明显闪烁。

- 条件与边界：
  占空比变化范围为 10%~90%（Pulse=100~900，Period=999）。单个呼吸周期（占空比 10%→90%→10%）时长约 2 秒，变化步进与延时应满足该周期要求，平滑无跳变，且不得影响 PWM 输出频率（1 kHz）。
