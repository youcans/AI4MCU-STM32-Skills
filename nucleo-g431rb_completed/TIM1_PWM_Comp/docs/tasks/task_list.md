## 2. 编程任务详细说明

### T01 启动 TIM1 CH1 与互补通道，输出带死区的互补 PWM 信号

#### 任务目标

TIM1 初始化完成后启动通道 1（CH1）与互补通道（CH1N）的 PWM 输出，并使能高级控制定时器主输出级；PA8（CH1）与 PB13（CH1N）持续输出频率 10 kHz、占空比 0.5、带约 500 ns 死区的互补 PWM 信号，实现并验证项目任务需求 PR-001。

#### 涉及文件

- 修改：Core/Src/main.c
- 无需新增文件

#### 主要修改位置

| 文件 | 函数或代码区域 | 处理内容 |
|---|---|---|
| Core/Src/main.c | main() 内 USER CODE BEGIN 2 / END 2 区域 | 位于 MX_TIM1_Init() 之后、while(1) 之前，承担启动 PWM 输出的职责：启动通道 1 与互补通道输出，并使能主输出级 |

#### 实施要点

- 启动 TIM1 通道 1（CH1）的 PWM 输出，并启动对应的互补通道（CH1N）输出。
- 使能高级控制定时器主输出级（MOE）；未使能时即使通道已启动，引脚也无信号输出。
- 不修改 MX_TIM1_Init() 中已有的频率、占空比、死区等参数配置（已满足需求）。
- 输出采用启动后持续运行方式，主循环无需额外处理；如主循环存在其它逻辑，不得影响已启动的输出。

#### 验证要求

- 工程编译通过、烧录运行无错误。
- 示波器测量 PA8：输出 10 kHz、占空比约 50% 的 PWM 信号。
- 示波器测量 PB13：输出与 PA8 互补的 PWM 信号，两路信号边沿之间死区时间约 500 ns。

## 3. 补充说明

- 按任务编号顺序实施；本任务为唯一编程任务。
- 高级控制定时器的输出受主输出级使能控制，验证时需确认输出级已使能，否则 PA8/PB13 无信号（初始工程分析 5.1 已确认初始工程未启动输出）。
- 编译、烧录、示波器测量为任务验证方式，不属于编程任务。
- 时钟源差异（工程使用 HSI 作 PLL 源）不影响本任务，无需处理。
