## 2. 编程任务详细说明

### T01 LD2 LED周期闪烁实现

#### 任务目标

系统上电后，主循环周期驱动板载LED LD2（PA5）输出翻转，每500ms切换一次亮灭状态（500ms亮、500ms灭交替循环），满足PR-001功能要求。

#### 涉及文件

- 修改：Core/Src/main.c
- 使用（不修改）：Core/Inc/main.h 中已有的 LD2_Pin、LD2_GPIO_Port 宏

#### 主要修改位置

| 文件 | 函数或代码区域 | 处理内容 |
|---|---|---|
| Core/Src/main.c | while (1) 主循环体内 USER CODE BEGIN 3 区域 | 循环体：翻转LD2引脚输出电平，并延时500ms |

#### 实施要点

- 使用 main.h 中已有的 LD2_Pin（GPIO_PIN_5）与 LD2_GPIO_Port（GPIOA）宏访问LD2引脚，无需重新定义
- 每轮循环翻转一次PA5输出电平（在现状态基础上翻转），随后延时500ms，形成500ms亮/500ms灭的周期循环
- 延时采用基于SysTick节拍的HAL延时接口；SysTick已由HAL_Init配置并使能，SysTick_Handler中调用HAL_IncTick()
- 上电初始电平已由MX_GPIO_Init配置为低电平（LED灭），无需在任务中额外设置初始状态

#### 验证要求

- 编译验证：使用CMake构建工程，编译通过且新增代码无错误、无警告
- 烧录运行验证：烧录至NUCLEO-G431RB并复位运行，板载LD2以约1Hz频率周期闪烁（每500ms切换一次亮灭状态）

## 3. 补充说明

- 编程任务共1项（T01），按任务编号顺序实施
- 延时精度依赖SysTick节拍周期（初始工程分析待确认事项1：当前按HAL默认1ms推断）；若实测闪烁周期偏离500ms，应先确认SysTick节拍周期配置
