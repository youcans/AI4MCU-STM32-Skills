| 编号 | 任务名称 | 任务概要 |
|---|---|---|
| T01 | 按键状态轮询读取与软件去抖 | 在主循环中轮询读取 B1 按键（PC13）电平并做软件去抖，得到稳定的按键当前状态；暂以 LED 电平方式（按住点亮、松开熄灭）验证按键检测的正确性 |

## 2. 编程任务详细说明

### T01 按键状态轮询读取与软件去抖

#### 任务目标

完成按键状态的轮询读取与软件去抖，系统能够稳定区分 B1 按键的按下与松开状态；以 LD2 电平方式指示按键状态（按住点亮、松开熄灭），用于验证按键检测的正确性。

#### 涉及文件

- 修改：Core/Src/main.c

#### 主要修改位置

| 文件 | 函数或代码区域 | 处理内容 |
|---|---|---|
| Core/Src/main.c | while(1) 内 USER CODE BEGIN 3 区域 | 主循环中周期性执行按键读取、去抖处理，并按稳定后的按键状态更新 LD2 电平 |
| Core/Src/main.c | USER CODE BEGIN PV 区域 | 去抖处理所需的按键状态记录变量 |
| Core/Src/main.c | USER CODE BEGIN PD 区域 | 去抖时长等可调整参数宏 |
| Core/Src/main.c | USER CODE BEGIN 4 区域 | 按键去抖处理的自定义函数（供主循环调用） |

#### 实施要点

- 按键读取直接使用 HAL GPIO 接口读取 USER_BTN（PC13），时间判断基于 HAL 时基（SysTick，经 HAL_GetTick 获取毫秒计数值），不使用 BSP 按键接口
- 去抖处理：按键电平发生跳变后，需持续稳定一段时间（去抖时长，实现时确定，参考 10~50 ms）才确认新状态；去抖期间保持原状态输出
- 每轮主循环完成读取与去抖后，按稳定后的按键状态控制 LD2：按下点亮、松开熄灭（T01 阶段的验证性行为，T02 将替换为翻转逻辑）
- 去抖处理输出的"稳定按键状态"将作为 T02 边沿检测的输入，实现时注意保持该结构可扩展

#### 验证要求

- 编译无错误，烧录后运行
- 按住 B1 时 LD2 点亮，松开后 LD2 熄灭
- 快速连按或按键抖动时 LD2 无明显闪烁异常（按住稳定点亮、松开稳定熄灭）

### T02 按键边沿检测与LED翻转控制

#### 任务目标

在 T01 稳定按键状态的基础上增加按下边沿检测，实现每次有效按下翻转一次 LD2 亮灭状态：持续按住不重复翻转，松开后可响应下一次按下，完成需求 PR-001 与 PR-002 的最终行为。

#### 涉及文件

- 修改：Core/Src/main.c

#### 主要修改位置

| 文件 | 函数或代码区域 | 处理内容 |
|---|---|---|
| Core/Src/main.c | while(1) 内 USER CODE BEGIN 3 区域 | 在 T01 按键处理基础上增加按下沿判定与 LD2 翻转，替换 T01 的电平指示行为 |
| Core/Src/main.c | USER CODE BEGIN PV 区域 | 上一次按键稳定状态的记录变量 |
| Core/Src/main.c | USER CODE BEGIN 4 区域 | 边沿检测处理的自定义函数（必要时新增或调整） |

#### 实施要点

- 在 T01 去抖处理结果之上，比较本次与上一次的稳定按键状态
- 仅在"上一次为松开、本次为按下"的按下沿产生一次触发：翻转 LD2 输出电平（HAL GPIO 翻转接口），实现 LED 亮灭切换
- 持续按住期间（连续多轮轮询均为按下状态）不产生重复触发；松开后再次按下时再次触发
- T01 的电平指示逻辑替换为翻转逻辑，去抖处理本身保持不变
- LD2 翻转后的亮灭状态由硬件输出电平决定，无需在软件中另行维护 LED 状态

#### 验证要求

- 编译无错误，烧录后运行
- 每次有效按下 B1，LD2 亮灭状态翻转一次
- 按住 B1 不放，LD2 仅翻转一次，不连续闪烁
- 松开后再次按下，LD2 再次翻转

## 3. 补充说明

- 按 T01 → T02 顺序实施；T02 依赖 T01 的去抖处理结果，属于在其基础上的功能扩展
- 去抖时长参数需求中未指定，由实现阶段确定（参考 10~50 ms），整定后宜定义为宏常量便于调整
- 按键读取不使用 main.c 中 BSP 演示脚手架生成的 BspButtonState 全局变量与 BSP 按键接口（该脚手架未包含按键初始化调用）；如需改用 BSP 接口，需另行确认并补充初始化
- 所有修改均位于 CubeMX USER CODE 区域内，避免后续使用 CubeMX 重新生成工程时被覆盖
- 烧录与调试使用板载 ST-LINK（SWD，PA13/PA14）
