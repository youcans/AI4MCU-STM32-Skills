## 2. 编程任务详细说明

### T01 锯齿波数据生成与JustFloat数据帧构建

#### 任务目标

完成该任务后，系统具备生成周期性锯齿波浮点采样数据，并按 `vofa_justfloat.md` 输出规范组装为JustFloat数据帧的能力：每个数据帧包含1个浮点采样值（CH_COUNT=1，小端字节序）和固定帧尾 0x00 0x00 0x80 0x7F，共8字节，数据存放在可供DMA发送使用的连续缓冲区中。该能力不依赖LPUART发送即可独立验证。

#### 涉及文件

- `Core/Src/main.c`（新增/修改）
- `Core/Inc/main.h`（新增/修改，如需定义相关常量与宏）

#### 主要修改位置

| 文件 | 函数或代码区域 | 处理内容 |
|---|---|---|
| Core/Inc/main.h | USER CODE BEGIN Private defines / USER CODE BEGIN Includes | 定义任务相关常量（锯齿波采样点数、帧长8字节、帧尾定义等）并提供必要的数据类型声明 |
| Core/Src/main.c | 私有变量区域（USER CODE BEGIN PV） | 声明锯齿波采样值数组与发送缓冲区（连续内存，满足DMA存储器地址递增要求） |
| Core/Src/main.c | USER CODE BEGIN 0 / USER CODE BEGIN 4 | 实现锯齿波数据生成函数与JustFloat帧组装函数：生成浮点采样序列并按 `float ch_data[1] + 帧尾` 结构写入发送缓冲区 |

#### 实施要点

- 锯齿波数据由浮点采样值按单调上升至峰值后骤降回零的周期性规律生成，形成往返递增的周期性波形；
- 每帧按 `vofa_justfloat.md` 规定的8字节结构组装：前4字节为单通道浮点数据（小端），后4字节为固定帧尾 0x00 0x00 0x80 0x7F；
- 发送缓冲区必须为连续内存且按字节对齐，以匹配DMA发送通道的存储器地址递增与字节对齐配置；
- 帧尾和帧结构必须严格符合 `vofa_justfloat.md`，串口数据流不添加任何换行符；
- 锯齿波采样点数、单帧数据量、发送周期等参数（见待确认事项C-03）应定义为可调整的常量，便于后续确认后修改。

#### 验证要求

- 编译通过；
- 单步或借助调试/串口工具核对发送缓冲区内容：每8字节的帧结构首4字节为当前锯齿波采样值的float（小端）表示、后4字节为 0x00 0x00 0x80 0x7F；
- 核对锯齿波序列数值呈周期性上升后归零的规律，帧尾完整且无额外换行。

### T02 LPUART1 DMA连续发送数据帧

#### 任务目标

完成该任务后，系统上电即使用已配置的DMA发送通道（DMA1_Channel1→LPUART1_TX）持续向板载虚拟串口发送T01构建的JustFloat数据帧，无需外部触发；PC端VOFA+以JustFloat数据引擎打开对应串口后可实时显示锯齿波波形。

#### 涉及文件

- `Core/Src/main.c`（新增/修改）

#### 主要修改位置

| 文件 | 函数或代码区域 | 处理内容 |
|---|---|---|
| Core/Src/main.c | USER CODE BEGIN 2 | 系统初始化完成后初始化锯齿波数据/发送缓冲区并启动首次DMA发送 |
| Core/Src/main.c | USER CODE BEGIN WHILE / USER CODE BEGIN 3 | 主循环中执行后续数据帧的持续发送（在传输完成基础上按发送周期重新触发），保持连续输出 |
| Core/Src/main.c | USER CODE BEGIN 4 | 实现传输完成回调（HAL_UART_TxCpltCallback弱函数，因USE_HAL_UART_REGISTER_CALLBACKS=0），用于在DMA NORMAL模式下传输完成后重新触发下一次发送，并推进锯齿波数据到下一帧 |

#### 实施要点

- 使用已链接到 hlpuart1.hdmatx 的DMA发送通道发起数据帧发送，无需CPU逐字节搬运；
- 由于DMA当前配置为NORMAL模式（见待确认事项C-04），连续发送需在每次传输完成后重新启动DMA发送，通过UART传输完成回调或主循环周期触发实现；
- 发送周期与锯齿波数据更新速率需保持一致，确保VOFA+显示连贯的锯齿波；采样点数与周期参数由常量控制（T01定义）；
- 确保每次重新触发时使用同一连续发送缓冲区，数据帧内容在合适时机更新为新的锯齿波采样值；
- 波特率115200为工程既定配置（见C-02），VOFA+侧保持一致并选择JustFloat数据引擎。

#### 验证要求

- 编译、烧录并在硬件上运行；
- PC打开与LPUART1虚拟串口对应的串口，设置波特率115200，数据引擎选择JustFloat；
- 预期结果：VOFA+实时显示周期性锯齿波波形，波形连续无中断。
