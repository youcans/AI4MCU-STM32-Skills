# 编程任务清单

## 1. 编程任务列表

| 编号 | 任务名称 | 任务概要 |
|---|---|---|
| T01 | 按键中断与LD2切换实现 | 实现 HAL_GPIO_EXTI_Callback 回调，使 B1 按键触发中断后切换 LD2 亮灭状态，打通"按键→EXTI中断→LED翻转"的完整功能链路 |
| T02 | 按键消抖处理 | 在中断处理中加入软件消抖，避免单次按压因机械抖动产生多次中断响应，确保单次按压 LD2 仅翻转一次 |

## 2. 编程任务详细说明

### T01 按键中断与LD2切换实现

#### 任务目标

完成该任务后，按下 B1 按键触发 EXTI 中断，中断处理中翻转 LD2 输出电平，实现 LED 亮灭切换（消抖加入前允许抖动引起的多次翻转）。

#### 涉及文件

- Core/Src/main.c（修改）

#### 主要修改位置

| 文件 | 函数或代码区域 | 处理内容 |
|---|---|---|
| Core/Src/main.c | USER CODE BEGIN 4 区域（文件末尾函数区） | 实现 HAL_GPIO_EXTI_Callback 回调：识别按键引脚触发源，翻转 LD2 输出 |

#### 实施要点

- 在 USER CODE 区实现 HAL_GPIO_EXTI_Callback，覆盖 HAL 弱默认空实现；USER CODE 区内容在 CubeMX 重新生成工程时保留
- 回调内判断触发引脚为 USER_BTN_Pin 时执行 LD2 电平翻转
- LD2 翻转使用 HAL GPIO 翻转接口，引脚使用 main.h 现有宏（LD2_Pin、LD2_GPIO_Port）
- 无需修改主循环与中断服务函数（EXTI15_10_IRQHandler 已调用 HAL_GPIO_EXTI_IRQHandler）

#### 验证要求

- 编译无错误
- 烧录后按下/松开 B1 按键，观察 LD2 状态发生变化
- 若 LD2 在松开而非按下时翻转，与触发边沿配置有关（见补充说明），非代码问题

### T02 按键消抖处理

#### 任务目标

完成该任务后，单次按键按压（含机械抖动过程）仅产生一次有效响应，LD2 仅翻转一次。

#### 涉及文件

- Core/Src/main.c（修改）

#### 主要修改位置

| 文件 | 函数或代码区域 | 处理内容 |
|---|---|---|
| Core/Src/main.c | USER CODE BEGIN 4 区域（HAL_GPIO_EXTI_Callback 内） | 在 T01 基础上增加时间间隔判断，过滤抖动产生的重复中断 |

#### 实施要点

- 基于系统时间（HAL_GetTick）记录上次有效响应时间，两次有效响应之间设置最小时间间隔，间隔内的中断视为抖动并忽略
- 消抖逻辑嵌入 T01 实现的回调内，不改变中断触发和 LED 翻转的原有行为
- 消抖间隔取值需兼顾抖动滤除效果与按键响应灵敏度

#### 验证要求

- 编译无错误
- 快速连按、长按、轻按按键，确认单次按压 LD2 仅翻转一次，且无漏响应

## 3. 补充说明

- 任务按 T01 → T02 顺序实施，T02 依赖 T01 完成。
- 触发边沿待确认事项（来自初始工程分析）：当前配置为上升沿触发（IT_RISING）且 PC13 无上下拉。若烧录验证时发现按键行为与"按下触发"不符（例如松开时才翻转），需返回 STM32CubeMX 修改触发边沿（下降沿或双边沿）及上下拉配置后重新生成工程。T01/T02 的代码实现与边沿选择无关，配置调整不影响已完成的代码。
- PC13 悬空风险：若按键电路无外部上拉，建议在 CubeMX 中为 PC13 配置内部上拉。
