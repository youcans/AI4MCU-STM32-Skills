# 项目任务需求文件

## 1. 项目信息

- 项目名称：TIM_IT_500ms
- 项目类型：基础定时器中断实验
- 项目目标：使用基础定时器 TIM6 每 500ms 产生一次更新事件，在更新中断服务程序中切换板载 LD2 指示灯状态，实现 LD2 周期闪烁（周期 500ms）。
- 开发板型号：nucleo-g431rb（NUCLEO-G431RB）
- MCU型号：STM32G431RBT6
- 文件状态：待确认

## 2. 项目功能要求

### PR-001 定时器周期中断

- 功能要求：
  - 使用 TIM6 基础定时器，配置为内部时钟源模式。
  - TIM6 每 500ms 产生一次更新事件并触发更新中断。
  - 在 TIM6 更新中断服务函数中切换板载 LD2（LED）指示灯的开关状态，使 LD2 以 500ms 周期闪烁。

- 条件与边界：
  - 系统时钟配置为 HSI + PLL，SYSCLK 达到 160MHz，APB1 定时器时钟为 160MHz。
  - TIM6 预分频值（Prescaler）和自动重载值（Period）的计算结果应使更新周期严格等于 500ms。
  - 中断处理需快速完成，仅在中断服务程序中执行 LED 状态的切换，不进行耗时操作。
