## 2. 编程任务详细说明

### T01 TIM6更新中断实现LD2周期闪烁

#### 任务目标

完成该任务后，TIM6 以内部时钟源运行，每 500ms 产生一次更新事件并触发更新中断；在周期到期回调中切换板载 LD2(PA5) 的输出状态，使 LD2 以 500ms 周期（亮 500ms、灭 500ms）闪烁。系统上电并完成外设初始化后即自动开始闪烁。

#### 涉及文件

- `Core/Src/main.c`（新增代码，不新建源文件）

#### 主要修改位置

| 文件 | 函数或代码区域 | 处理内容 |
|---|---|---|
| Core/Src/main.c | USER CODE BEGIN 2 / USER CODE END 2（位于 MX_TIM6_Init() 之后） | 启动 TIM6 定时器并使其产生更新中断：调用启动并中断模式运行的接口，完成定时周期闪烁的功能使能 |
| Core/Src/main.c | USER CODE BEGIN 4（用户自定义代码区域） | 实现周期到期回调函数 `HAL_TIM_PeriodElapsedCallback`，在其中对 TIM6 更新事件进行响应，切换板载 LD2(PA5) 的输出状态 |

#### 实施要点

- 在初始化完成后（MX_TIM6_Init() 之后）启动定时器，采用中断模式启动，使能 TIM6 更新中断并开始计数。
- 实现周期到期回调 `HAL_TIM_PeriodElapsedCallback`，该回调由 HAL 在 TIM6 更新中断时经 `HAL_TIM_IRQHandler(&htim6)` 触发。
- 回调中通过参数句柄的外设实例（Instance 为 TIM6）判断事件来源，避免与其它定时器/事件相互干扰。
- 在回调中切换板载 LD2(PA5) 的输出电平，实现 500ms 周期闪烁；切换采用 GPIO 翻转方式。
- 回调内仅执行 LED 状态切换，不进行耗时操作，保证中断处理及时。

#### 验证要求

- 工程编译通过，无编译错误与告警（CMake 构建）。
- 烧录运行后，观察板载 LD2(PA5)：以 500ms 周期闪烁（每 500ms 亮/灭交替一次），与需求 PR-001 一致。

## 3. 补充说明

- 按任务编号顺序实施，本任务为唯一任务，无任务依赖。
- 时钟（SYSCLK/APB1 定时器时钟 160MHz）、TIM6 定时参数（PSC=1599、ARR=49999，更新周期=500ms）、GPIO（PA5 输出）、TIM6 中断向量（`TIM6_DAC_IRQHandler`、NVIC 使能）均已由初始工程配置就绪，T01 仅需在 USER CODE 区域补充启动使能与回调实现。
